## 本地工具检查

```sh
python3 tools/test_station_dhcp.py
python3 tools/test_terminal_card_io.py
python3 tools/test_assemble_card.py
```

已验证 DHCP 获取、续租和释放，拒绝其他网卡和命令注入参数；卡守卫覆盖 USB 导出、只读、卸载及异常文件系统；组装检查覆盖固定指纹、地址范围、默认关闭主码流、文件清单、不覆盖既有产物和私钥误用拒绝。

Python 和 shell 语法检查通过。Zig 0.14.1 已实际编译 Dropbear 与补丁程序，两者均为 ARM ELF32 静态程序；真实构建产物已完成本地组装与清单核验。构建产物、临时测试密钥和组装目录不提交。

## 未完成的验证

- 512 MiB 是地址布局合计，没有执行全物理内存容量或地址别名压测，也没有测量 CPU 实际频率。
- Wi-Fi 长期稳定性、DHCP 地址变化与反复断电恢复尚需进一步实机测试。
- 文件服务不判断最新 MP4 是否已完成写入；客户端应避免下载仍在增长的文件。
- Linux 单侧卸载不能证明另一套系统已停止写卡，维护统一使用电脑 USB 存储模式。
- `s36_card_write_allowed` 是历史函数名，目前用于文件服务可用性判断；隔离测试通过不表示允许在录像期间由 Linux 写卡。
- 原厂应用分区恢复候选只做离线构建，没有实测刷回，不能保证免拆机恢复。
- 公开组装模板尚未重新安装到设备进行新的启动测试；本地检查与已有实机结果分开记录。
